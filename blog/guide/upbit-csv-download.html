광고 영역

업비트 앱에서 거래내역 CSV 다운로드하는 방법

앱 마이페이지 → 거래내역 → 기간 설정 → 내보내기

업비트 앱(iOS/Android) → 하단 탭 → 마이페이지 → 거래내역 → 조회 기간 설정(최대 3년) → 내보내기(엑스포트) → 이메일 또는 파일로 저장. CSV 파일에는 매수·매도 시각, 코인명, 수량, 가격, 수수료가 모두 포함됩니다. 세금 신고에 필요한 모든 정보가 들어있습니다.

최대 3년치 다운로드 가능 — 연도별 분리 권장

업비트 CSV는 최대 3년치까지 한 번에 내려받을 수 있습니다. 단, 2027년 세금 신고용이라면 2027년 1월 1일~12월 31일로 기간을 정확히 설정하는 것이 중요합니다. 연도별로 파일을 분리해 저장해두면 나중에 찾기 편합니다.

업비트 PC 웹에서 CSV 다운로드하는 방법

웹 브라우저 업비트 로그인 → 거래내역 메뉴

업비트 웹사이트(upbit.com) → 로그인 → 마이페이지 → 투자내역 → 거래내역 → 기간 설정 → CSV 다운로드. PC 웹은 큰 화면으로 작업하기 편하고, 기간을 세밀하게 설정할 수 있습니다. 앱보다 다운로드 속도가 빠른 경우도 있습니다.

CSV 파일 열기 — 엑셀·구글시트 활용법

업비트 CSV는 한글(EUC-KR) 인코딩입니다. 엑셀에서 바로 열면 한글이 깨질 수 있습니다. 올바르게 여는 방법: 엑셀 → 데이터 → 텍스트 가져오기 → 인코딩 'EUC-KR' 선택. 또는 구글시트에 업로드하면 자동 인코딩 처리가 됩니다.

업비트 CSV를 세금 계산기에 업로드하는 법

CryptoTax.cloud CSV 세금 계산기 업로드 방법

CSV 세금 계산기에 접속 → 업비트 CSV 파일 업로드 → 자동으로 이동평균법 취득원가 계산 → 코인별 양도차익과 예상 세금 확인. 여러 연도 파일을 업로드하면 통합 계산도 가능합니다. 수동 계산 없이 빠르게 세금을 파악할 수 있습니다.

CSV 세금 계산 시 주의사항

빗썸, 코인원 등 다른 거래소도 이용했다면 각 거래소 CSV를 모두 합산해야 정확한 세금이 계산됩니다. 거래소별 CSV 형식이 다를 수 있으니, 계산기에 업로드 전 파일 형식을 확인하세요. 의심스러우면 세무사와 상담하는 것도 좋습니다.

자주 묻는 질문 요약

업비트 거래내역 CSV는 앱 또는 웹에서 마이페이지 → 거래내역 → 기간 설정 → 내보내기로 다운로드합니다. 최대 3년치까지 조회 가능하며, 다운로드한 CSV를 세금 계산기에 업로드하면 자동으로 세금이 계산됩니다.

❓ 자주 묻는 질문

업비트 거래내역 CSV는 어디서 다운로드하나요?

업비트 앱: 메뉴 → 거래내역 → 기간 선택 → CSV 내보내기. 업비트 웹: 마이페이지 → 거래내역 → 검색 → Excel/CSV 다운로드. 최대 3년치(1,095일)까지 조회 가능합니다.

업비트 CSV 파일에는 어떤 정보가 담겨 있나요?

거래 일시, 코인 종류, 매수/매도 구분, 거래 수량, 거래 단가(원화), 거래 금액, 수수료가 포함되어 있습니다. 세금 계산기에 업로드하면 이 데이터를 바탕으로 이동평균 취득원가와 양도차익을 자동 계산합니다.

업비트 CSV를 세금 계산기에 어떻게 업로드하나요?

CryptoTax.cloud CSV 세금 계산기 페이지에서 '파일 선택' 버튼을 누르고 다운로드한 업비트 CSV 파일을 선택하면 됩니다. 파일을 선택하면 자동으로 거래내역을 분석하여 양도차익과 예상 세금을 계산합니다.

3년 이상 된 거래내역도 필요한가요?

취득원가 계산을 위해 가능한 오래된 거래내역이 필요합니다. 2027년 과세 시작 전 취득한 코인은 의제취득가액(2026년 12월 31일 시가) 또는 실제 취득가액 중 유리한 방향을 선택할 수 있으므로, 초기 매수 내역을 보관하는 것이 좋습니다.

빗썸 CSV도 같은 계산기에서 사용할 수 있나요?

네. CryptoTax.cloud CSV 세금 계산기는 업비트와 빗썸 CSV 파일 형식을 모두 지원합니다. 두 거래소 파일을 각각 업로드하면 자동으로 합산 계산되어 전체 세금을 한 번에 확인할 수 있습니다.
