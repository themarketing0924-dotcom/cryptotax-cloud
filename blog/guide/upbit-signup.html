광고 영역

업비트 가입 전 필요한 것 3가지

카카오 계정 — 없으면 먼저 만들어두기

업비트는 카카오 계정으로 가입합니다. 카카오톡을 사용하고 있다면 그 계정을 그대로 사용하면 됩니다. 카카오 계정이 없는 경우 카카오 앱에서 먼저 계정을 만들어두세요. 이메일 계정으로 별도 가입은 불가능합니다.

신분증 + 케이뱅크(또는 농협) 계좌 필요

신분증(주민등록증 또는 운전면허증)으로 실명 인증이 필요합니다. 원화 입출금을 위해 케이뱅크 계좌가 필요합니다(농협도 가능하지만 케이뱅크가 간편). 케이뱅크 앱을 미리 설치해 계좌를 개설해두면 업비트 가입 속도가 빨라집니다.

업비트 회원가입 단계별 가이드

1단계 — 카카오 계정 연동과 신분증 실명 인증

업비트 앱 설치 → '카카오로 시작' 선택 → 카카오 로그인 → 업비트 약관 동의 → 신분증 사진 촬영(또는 NFC 인식) → 실명 인증 완료. 인증은 보통 1~2분 내에 완료됩니다. 신분증 촬영 시 빛 반사 없이 선명하게 찍어야 인증이 통과됩니다.

2단계 — 케이뱅크 계좌 연결과 원화 입금

실명 인증 완료 후 → 케이뱅크 계좌 연결 → ARS 또는 앱 인증 → 연결 완료. 이후 케이뱅크 앱에서 업비트로 원화를 이체하면 즉시 반영됩니다. 처음에는 10만~50만원 소액으로 시작해 시스템에 익숙해지는 것을 권장합니다.

가입 후 첫 코인 매수와 보안 설정

첫 코인 매수 — 비트코인 소액부터 시작

업비트 → 거래 → KRW 마켓 → 'BTC' 검색 → 매수 탭 → 금액 입력 → 매수. 최소 5,000원부터 매수 가능합니다. 처음에는 비트코인 또는 이더리움처럼 검증된 코인부터 시작하는 것이 안전합니다. 코린이 완전 입문 가이드도 함께 읽어보세요.

업비트 앱 보안 설정 — 반드시 해야 할 것

보안 강화를 위해 반드시 설정할 것: ① 2단계 인증(2FA) 활성화. ② 출금 지연 설정(24시간 출금 지연). ③ 생체인증(지문·Face ID) 활성화. ④ 이메일/SMS 거래 알림 설정. 계정 보안에 투자하는 것이 코인 보안의 첫걸음입니다.

자주 묻는 질문 요약

업비트 가입은 카카오 계정 연동과 실명 인증(신분증)이 필요합니다. 원화 입출금을 위해 케이뱅크 또는 농협은행 계좌가 필요합니다. 반드시 공식 사이트(upbit.com)에서만 가입하고 피싱 사이트를 주의하세요.

❓ 자주 묻는 질문

업비트 회원가입 절차는 어떻게 되나요?

① 업비트 공식 앱(iOS/Android) 또는 upbit.com 접속 ② 카카오 계정으로 가입 ③ 신분증 촬영으로 실명 인증 ④ 케이뱅크 또는 농협은행 계좌 연동 ⑤ AML(자금세탁방지) 질문지 작성. 보통 1~3일 이내 승인됩니다.

업비트 원화 입출금을 위해 어떤 은행 계좌가 필요한가요?

케이뱅크 계좌 또는 농협은행 계좌(2024년 계약 종료로 신규 불가, 기존 고객 유지)가 필요합니다. 케이뱅크 계좌가 없다면 케이뱅크 앱에서 비대면으로 개설한 후 업비트와 연동하면 됩니다.

업비트 가입 시 나이 제한이 있나요?

만 19세 이상 성인만 가입 가능합니다. 미성년자는 법정대리인(부모) 동의가 있어도 가입이 불가합니다. 타인 명의를 빌려 가입하는 것은 금융실명제 위반으로 법적 처벌을 받을 수 있습니다.

업비트 가입 후 보안 설정은 어떻게 해야 하나요?

① OTP(Google Authenticator) 또는 SMS 2단계 인증 설정 ② 출금 지연 기능 활성화(출금 신청 24시간 후 처리) ③ 로그인 알림 설정. 피싱 사이트·사기 문자에 주의하고 업비트 공식 앱에서만 접속하세요.

업비트에서 코인을 사면 세금이 바로 발생하나요?

아니요. 코인을 보유만 하는 동안은 세금이 없습니다. 실제로 매도(판매)해서 수익이 실현된 경우에만 2027년부터 22% 세금이 부과됩니다. 매수 시점부터 거래 내역을 꼼꼼히 기록해두세요.
