업비트 매도 전 확인 사항

실명 인증 계좌 연결 여부

업비트에서 코인을 매도한 원화를 출금하려면 실명 확인된 은행 계좌가 연결되어 있어야 합니다. 케이뱅크 계좌 연결이 가장 빠르며, 국민·신한 등 주요 은행도 지원합니다. 계좌 미연결 상태에서도 매도 자체는 가능하지만 출금이 불가합니다.

KRW 마켓 vs BTC 마켓

업비트에는 KRW(원화) 마켓과 BTC(비트코인) 마켓이 있습니다. 대부분의 초보 투자자는 KRW 마켓에서 거래합니다. BTC 마켓에서 매도하면 원화가 아닌 비트코인으로 받게 됩니다.

마켓결제 통화수수료초보자 추천
KRW 마켓원화0.05%✅ 추천
BTC 마켓비트코인0.05%고급자용

시장가 매도 — 즉시 체결하는 방법

앱 기준 단계별 안내

  1. 업비트 앱 실행 → 하단 투자 탭
  2. 매도할 코인 선택 (예: 비트코인)
  3. 화면 하단 매도 버튼 탭
  4. 주문 유형에서 시장가 선택
  5. 매도 수량 입력 (전량 매도 시 최대 버튼)
  6. 예상 체결 금액 확인 → 매도 주문 탭
  7. 본인 인증(PIN 또는 생체) 후 주문 완료
📘 참고

시장가 매도는 현재 가장 좋은 매수 호가에 즉시 체결됩니다. 급등·급락 구간에서는 예상 가격과 실제 체결 가격이 약간 다를 수 있습니다(슬리피지).

지정가 매도 — 원하는 가격에 팔기

지정가 매도 사용하는 경우

목표 수익률에 도달했을 때 자동 매도되도록 설정하고 싶다면 지정가 매도를 이용합니다. 예를 들어 비트코인이 1억2,000만원에 도달하면 자동 매도되도록 미리 주문을 넣어둘 수 있습니다.

지정가 매도 단계

  1. 매도 화면에서 주문 유형 지정가 선택
  2. 원하는 매도 가격 직접 입력
  3. 매도 수량 입력
  4. 매도 주문 — 주문이 미체결 상태로 대기
  5. 가격 도달 시 자동 체결
💡 팁

지정가 매도 주문은 언제든 취소 가능합니다. 투자내역 → 미체결 주문에서 주문을 확인하고 필요 시 취소하세요.

매도 후 원화 출금 방법

원화 출금 단계

  1. 업비트 앱 → 하단 입출금 탭
  2. 원화 선택
  3. 출금 탭 선택
  4. 출금 금액 입력
  5. 연결된 은행 계좌 확인 → 출금 신청

출금 처리 시간과 한도

구분내용
처리 시간영업일 기준 1~2일 (주말·공휴일 제외)
1회 최소 출금1,000원
출금 수수료무료
출금 계좌실명 인증 연결 계좌만 가능
⚠️ 주의

매도 수익이 연 250만원을 초과하면 2027년부터 22% 가상자산 세금 납부 대상입니다. 매도 전 세금을 미리 계산해두세요.

자주 묻는 질문

업비트 코인을 매도하면 즉시 원화로 받을 수 있나요?
시장가 매도는 주문 즉시 체결되어 원화 잔고에 반영됩니다. 다만 원화를 은행 계좌로 출금하려면 1~2 영업일이 소요됩니다.
업비트 매도 수수료는 얼마인가요?
업비트 KRW 마켓 매도 수수료는 거래 금액의 0.05%입니다. 100만원 매도 시 500원, 1,000만원 매도 시 5,000원입니다.
업비트 원화 출금은 얼마나 걸리나요?
영업일 기준 1~2일 내 처리됩니다. 주말·공휴일 신청분은 다음 영업일에 처리됩니다.
부분 매도도 가능한가요?
네. 매도 수량을 직접 입력하면 보유 수량의 일부만 매도할 수 있습니다. 전량 매도 시 최대 버튼을 누르세요.
