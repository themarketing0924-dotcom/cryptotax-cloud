NFT 세금 기본 원칙 — 유형별 과세 체계 2027

NFT는 가상자산인가? — 세금 체계 결정 문제

NFT(대체 불가능한 토큰)는 블록체인 기반 디지털 자산이지만, 2027년 시행 가상자산 양도소득세 과세 대상에 모두 포함되는지는 NFT의 종류에 따라 달라질 수 있습니다. 국세청은 일반적인 NFT 매매 수익을 가상자산 양도소득세 대상으로 처리하는 것을 기본 방향으로 합니다.

NFT 수익 유형과세 체계세율비고
NFT 매매 차익가상자산 양도소득세22%250만 원 공제
NFT 민팅 후 판매 (반복)사업소득6~45%종합소득세 합산
NFT 민팅 후 판매 (일회성)기타소득20%250만 원 공제
NFT 로열티 수익기타소득/사업소득20% or 6~45%반복성에 따라
📘 참고

NFT 과세 세부 기준은 아직 유권해석이 완전히 정립되지 않은 부분이 있습니다. 특히 게임 아이템 NFT, 실물 연계 NFT, 유틸리티 NFT 등은 과세 체계가 다를 수 있습니다. 대규모 NFT 거래 시 세무사 상담을 권장합니다.

NFT 매매 세금 — 취득원가 계산법

NFT 취득원가 계산 — 이더리움 기준

NFT를 이더리움(ETH)으로 매수했다면, 취득원가는 매수 시점에 지불한 ETH를 원화로 환산한 금액입니다. 예를 들어 2024년에 0.5 ETH(당시 시가 150만 원)로 NFT를 구매했다면 취득원가는 150만 원입니다. 매수 시 가스비(거래 수수료)도 취득원가에 포함됩니다.

NFT 매매 세금 계산 사례

0.5 ETH(150만 원)에 구매한 NFT를 2027년에 2 ETH(당시 시가 1,000만 원)에 판매했다면:

양도차익 = 1,000만 - 150만 = 850만 원

과세표준 = 850만 - 250만(공제) = 600만 원

세액 = 600만 × 22% = 132만 원

⚠️ 주의

NFT를 ETH로 구매·판매하는 경우, NFT 거래 시점에 ETH 자체의 양도차익도 발생할 수 있습니다. ETH 취득원가와 NFT 구매에 사용한 ETH의 시가 차이가 추가 과세 이벤트가 됩니다.

NFT 민팅·로열티 수익 세금

창작자 NFT 민팅 판매 — 사업소득 vs 기타소득

자신이 만든 NFT를 판매하는 창작자의 경우, 반복적·지속적으로 NFT를 만들어 판매하면 사업소득으로 분류됩니다. 이 경우 다른 소득과 합산해 종합소득세 6~45% 세율이 적용됩니다. 단순 일회성 판매는 기타소득 20%가 적용될 수 있습니다.

NFT 로열티 — 2차 거래 수익

NFT 2차 시장에서 거래될 때마다 원 창작자에게 지급되는 로열티도 기타소득 또는 사업소득으로 과세됩니다. 오픈씨(OpenSea), 블러(Blur) 등 해외 플랫폼의 로열티도 국내 신고 대상입니다.

💡 팁

NFT 창작자는 매 작품 판매 기록과 로열티 수령 내역을 플랫폼에서 CSV로 다운로드해 보관하세요. 오픈씨는 계정 Activity 탭에서 거래내역 확인이 가능합니다.

NFT 세금 신고 방법과 절세 전략

신고 절차 — 5월 종합소득세 신고

  1. 연간 NFT 거래내역 수집 (플랫폼 CSV + 블록체인 익스플로러)
  2. 각 NFT 매매·민팅·로열티 수익 집계
  3. 취득원가 계산 (매수 시점 원화 환산 + 가스비)
  4. 유형별 소득(양도소득·기타소득·사업소득) 분류
  5. 다음 해 5월 홈택스에서 종합소득세 신고
"NFT 세금의 핵심은 '유형 분류'입니다. 같은 NFT 수익이라도 매매냐 창작이냐에 따라 세금 체계가 달라집니다."

NFT 수익이 복잡하게 얽혀 있다면 세금 계산기로 기본 양도소득세부터 계산하고, 세무사 상담으로 확정하는 절차를 권장합니다.

자주 묻는 질문

NFT를 팔면 세금을 내야 하나요?

네. 2027년부터 NFT 매매 수익도 가상자산 양도소득세(22%) 과세 대상입니다. NFT 취득원가(민팅 비용 또는 매수 가격)와 매도가의 차액에 250만 원 공제 후 22%가 부과됩니다.

NFT 민팅 수익도 세금이 붙나요?

NFT를 직접 민팅해 판매하면 사업소득 또는 기타소득으로 과세됩니다. 반복적·지속적 판매는 사업소득(6~45% 누진세율), 일회성은 기타소득(20%)으로 처리됩니다.

NFT 로열티 수익에도 세금이 붙나요?

네. NFT 2차 판매 시 원 창작자에게 지급되는 로열티도 기타소득 또는 사업소득으로 과세됩니다. 연 250만 원 이하라도 신고 의무는 있습니다.
