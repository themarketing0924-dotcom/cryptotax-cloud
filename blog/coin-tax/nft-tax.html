NFT 세금 기본 원칙 — 2027년 과세 대상인가

NFT 양도 수익 — 가상자산 양도소득세 적용

2027년부터 NFT 거래로 발생한 수익도 가상자산 양도소득세(22%)의 과세 대상입니다. NFT를 사서 더 높은 가격에 팔면 매도가 - 취득원가 - 250만원(연간 기본공제)에 22%를 납부합니다. NFT도 코인과 동일한 기준으로 이동평균법 취득원가를 계산합니다.

NFT 발행(민팅) 수익의 세금 처리

NFT를 직접 창작·발행(민팅)해 판매한 수익은 양도소득이 아닌 사업소득 또는 기타소득으로 처리될 수 있습니다. 이 경우 세율 구조가 달라질 수 있으므로 민팅 수익이 상당한 경우 세무사 상담이 필요합니다.

NFT 세금 계산 방법 — 취득가·매도가 산정

NFT 취득원가 — 민팅 비용 + 가스피(수수료)

NFT 취득원가는 구매 가격 + 가스피(이더리움 네트워크 수수료)를 합산합니다. 직접 민팅한 경우 민팅 비용(가스피)이 취득원가가 됩니다. 취득원가 계산을 위해 구매 당시 ETH 시가와 가스피 ETH 수량을 기록해두는 것이 중요합니다.

ETH·SOL로 거래한 NFT의 세금 계산

ETH로 NFT를 구매하면 두 가지 세금 이슈가 발생합니다. ① ETH 매도로 인한 코인 양도소득세. ② NFT 취득 후 매도 시 NFT 양도소득세. 코인으로 NFT를 거래할 때마다 코인 양도차익이 발생하므로 복잡한 세금 계산이 필요합니다. 정확한 기록 유지가 핵심입니다.

NFT 투자자 절세 전략

NFT 손실 코인과 손익통산 가능 여부

NFT 거래 손실과 코인 거래 수익은 손익통산이 가능합니다. 예를 들어 코인 수익 500만원 + NFT 손실 200만원 = 과세표준 300만원 - 250만원(기본공제) = 50만원 × 22% = 11만원. 손실 NFT를 연말 전에 정리해 세금을 줄이는 전략이 유효합니다.

NFT 세금 신고 시 필요한 서류

NFT 세금 신고를 위해 보관해야 할 것: ① 모든 NFT 구매·판매 거래 해시(블록체인 기록). ② ETH·SOL 등 코인의 취득원가 증빙. ③ 민팅 비용·가스피 기록. NFT 거래 내역은 이더스캔(etherscan.io) 등에서 지갑 주소로 조회할 수 있습니다.

자주 묻는 질문 요약

국세청은 NFT를 가상자산으로 분류해 2027년부터 22% 양도소득세를 부과합니다. NFT 취득원가는 구매 시 지불한 ETH 원화 환산 금액 + 가스비입니다. 창작 NFT 판매는 사업소득으로 분류될 수 있습니다.

❓ 자주 묻는 질문

NFT 판매 수익에도 코인 세금이 적용되나요?

네. 국세청은 NFT를 가상자산으로 분류하여 2027년부터 양도소득세 22%를 부과합니다. NFT 구매·판매·교환 모두 과세 대상이며, 연간 250만원 기본공제가 적용됩니다.

NFT 취득원가는 어떻게 계산하나요?

NFT 구매 시 지불한 금액(ETH 기준이면 구매 당일 ETH 시세 × 수량)이 취득원가입니다. 오픈씨 등 플랫폼 수수료와 가스비도 취득 부대비용으로 원가에 포함됩니다.

직접 창작한 NFT를 판매하면 세율이 다른가요?

창작 NFT 판매는 사업소득으로 분류될 가능성이 높습니다. 사업소득은 종합소득세 누진세율(6~45%) 적용 대상으로 양도소득세(22%)와 구조가 다릅니다. 전문가 상담을 권장합니다.

해외 NFT 마켓플레이스(오픈씨 등) 수익도 신고 의무가 있나요?

네. 한국 거주자는 국내외 모든 NFT 거래 수익을 신고해야 합니다. 해외 플랫폼에서 받은 ETH 수익도 수령 시점 환율로 원화 환산하여 과세표준에 포함해야 합니다.

NFT 투자 손실이 났을 때 절세할 수 있나요?

동일 과세연도 내 NFT 손실은 다른 코인 수익과 손익통산이 가능합니다. 코인 수익 500만원, NFT 손실 300만원이면 순이익 200만원(250만원 이하)으로 세금이 0원이 됩니다.
