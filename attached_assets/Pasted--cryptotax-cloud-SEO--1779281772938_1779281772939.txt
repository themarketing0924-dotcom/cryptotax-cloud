## **✅ 현재 잘 되어 있는 부분 (강점)**

현재 사이트는 기술적 SEO 기반이 상당히 잘 갖춰져 있습니다. 네이버 서치어드바이저 검색진단 결과에서도 전 항목 체크(✓)가 확인되었으며, 실제 소스코드 점검에서도 다음 요소들이 정상적으로 적용되어 있습니다.

**기술적 SEO 기반 완성도 (약 80점 수준)**

- `robots.txt`가 구글봇/Yeti(네이버)/Daumoa(다음)/bingbot/GPTBot/ClaudeBot 등 모든 주요 크롤러별로 세분화되어 완벽하게 설정되어 있고, sitemap URL도 명시되어 있습니다.
- `sitemap.xml`에 메인 페이지, 도구(tools/) 27개, 블로그(blog/) 약 60개 이상의 URL이 체계적으로 등록되어 있으며 `lastmod`, `changefreq`, `priority` 값도 모두 설정되어 있습니다.
- 구글 서치콘솔(`google-site-verification`)과 네이버 서치어드바이저(`naver-site-verification`) 인증이 **이중으로** 완료되어 있습니다.
- Canonical 태그(`<link rel="canonical">`)가 메인 페이지에 정확히 적용되어 있습니다.
- Open Graph(OG) 및 Twitter Card 메타태그가 완벽하게 구성되어 있으며 OG 이미지도 1584×672 규격으로 제작되어 있습니다.
- Schema.org JSON-LD (`WebSite` 타입 + `SearchAction` potentialAction)이 적용되어 있고, `robots` 메타 태그에서 모든 검색엔진에 `index, follow`가 명시되어 있습니다.
- GA4(`G-59PKBNRPBZ`), 네이버 애널리틱스(`wcs_add["wa"]`), 구글 애드센스(`ca-pub-9721493540498478`)가 모두 탑재되어 있어 수익화 인프라는 완성되어 있습니다.
- RSS 피드가 설정되어 있어 네이버/구글 뉴스 수집 가능성이 열려 있습니다.
- 다음 웹마스터 PIN이 robots.txt에 포함되어 있어 다음(카카오) 수집 인증도 되어 있습니다.
- 라이트/다크 테마 자동 전환, 모바일 반응형 햄버거 메뉴, sticky 네비게이션 등 UX가 잘 구성되어 있습니다.

## **❌ 문제점 및 개선이 필요한 부분 (긴급도 순)**

### **[긴급 🔴] 1. Schema Markup이 부족함 — FAQ·HowTo·Tool 구조화 데이터 미적용**

현재 메인 페이지에는 `WebSite` 타입만 적용되어 있고, **FAQ Schema**, **HowToStep Schema**, **FinancialProduct Schema** 등이 전혀 없습니다. 메인 페이지 하단에 "코인 세금은 언제부터 내야 하나요?" 등 8개의 FAQ가 있음에도 불구하고 Schema가 없기 때문에 구글 검색결과에서 **리치 스니펫(Rich Snippet) FAQ 박스**가 노출되지 않습니다. FAQ 리치 스니펫은 클릭률(CTR)을 최대 30~50% 끌어올릴 수 있는 핵심 요소입니다.

**즉시 조치 사항:** 메인 페이지 및 각 블로그 페이지 `<head>`에 아래와 같은 FAQ Schema를 추가해야 합니다.

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "코인 세금은 언제부터 내야 하나요?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "2027년 1월 1일부터 가상자산 양도소득세가 부과됩니다."
      }
    }
  ]
}
```

또한 계산기 도구 페이지에는 **SoftwareApplication** 또는 **WebApplication** Schema를, 블로그 가이드 글에는 **Article** + **BreadcrumbList** Schema를 각 페이지별로 적용해야 합니다.

### **[긴급 🔴] 2. 내부 링크 구조 최적화 부족 — 사일로 구조 미구현**

현재 사이트는 메인 페이지에서 도구와 블로그 링크를 나열하는 방식이지만, **SEO 사일로(Silo) 구조**가 명확하지 않습니다. 구글 크롤러가 페이지 간 주제 연관성을 파악하려면 콘텐츠가 계층적으로 연결되어야 합니다. 예를 들어, "코인 세금 2027 가이드" 블로그 글이 "세금 계산기" 도구 페이지와 양방향 링크로 연결되고, "업비트 세금 가이드"가 "업비트 CSV 다운로드 가이드"로 연결되는 체계적 내부 링크망이 필요합니다. 현재 블로그 글들이 독립적으로 존재하는 경우가 많아 **링크 주스(Link Juice) 전달이 비효율적**입니다.

**즉시 조치 사항:** 각 블로그 글 말미에 "관련 계산기 바로 가기"와 "관련 가이드 3선" 위젯을 추가하고, 도구 페이지에서도 관련 블로그 글로 링크를 연결하는 허브-앤-스포크(Hub-and-Spoke) 구조를 구축해야 합니다.

### **[중요 🟠] 3. 사이트 제목(Title) 키워드 전략 아쉬움**

현재 메인 페이지 타이틀은 **"코인 세금 계산기 2027 | 업비트·빗썸 무료"** 로 설정되어 있습니다. 이는 잘 만들어진 타이틀이지만, "2027" 연도 태그가 시간이 지나면 구식이 될 위험이 있고, **구글 검색 기준 최우선 키워드인 "가상자산 세금 계산기"**가 누락되어 있습니다. 네이버와 구글에서 검색 의도가 미묘하게 달라서 한국 투자자들은 "코인"이라는 단어를 쓰지만 구글은 "가상자산", "암호화폐" 등의 공식 용어로도 많이 검색합니다.

**즉시 조치 사항:** 타이틀을 `"코인 세금 계산기 2027 | 가상자산 양도소득세 업비트·빗썸 무료"` 형태로 개선하거나, 각 서브 페이지의 타이틀에 더 다양한 키워드 변형을 분산 배치해야 합니다.

### **[중요 🟠] 4. Page Speed & Core Web Vitals 점검 필요**

소스코드를 보면 CSS가 모두 `<head>` 인라인 스타일로 작성되어 있고, 네이버 애널리틱스 스크립트가 동기(synchronous) 방식으로 로드되고 있습니다. 특히 `//wcs.pstatic.net/wcslog.js` 는 `async` 속성이 없어 **렌더링 블로킹(Render-Blocking)**을 일으킬 수 있습니다. 구글의 Core Web Vitals(LCP, CLS, FID/INP) 점수가 낮으면 검색 순위에 직접적인 페널티가 발생합니다.

**즉시 조치 사항:** 구글 PageSpeed Insights(https://pagespeed.web.dev/)에서 모바일/데스크톱 점수를 각각 측정하고, 네이버 wcslog.js 스크립트에 `async` 또는 `defer` 속성을 추가해야 합니다. 이미지 파일들은 WebP 포맷으로 변환하고, 폰트 로딩에 `font-display: swap`을 적용해야 합니다.

### **[중요 🟠] 5. 빙(Bing) 웹마스터 인증 미완료**

소스 코드에 `<!-- <meta name="msvalidate.01" content="" /> -->` 라는 주석 처리된 빙 인증 코드가 있습니다. 빙은 글로벌 시장 점유율 약 10%, 그리고 **ChatGPT/Copilot의 웹 검색 기반**이기 때문에 한국 유저도 적지 않게 유입될 수 있습니다. 특히 ChatGPT가 "코인 세금 계산기 알려줘"라고 묻는 사용자에게 답변할 때 Bing 인덱스를 사용하므로, 빙 웹마스터 등록은 AI 검색 시대에 매우 중요합니다.

**즉시 조치 사항:** https://www.bing.com/webmasters 에서 인증 코드를 발급받아 주석을 해제하고 적용해야 합니다.

### **[개선 🟡] 6. 애드센스 광고 배치 최적화 필요**

현재 애드센스 스크립트는 탑재되어 있으나, **광고 단위 배치 전략**이 최적화되어 있는지 확인이 필요합니다. 금융/세금 키워드는 CPC(클릭당 단가)가 가장 높은 카테고리 중 하나로, "코인 세금", "가상자산 양도소득세", "업비트 세금 신고" 등의 키워드는 클릭당 수백~수천 원을 기대할 수 있습니다. 하지만 계산기 도구 페이지는 사용자가 계산에 집중하여 광고를 클릭하지 않을 수 있어, **블로그 콘텐츠 페이지가 실질적 수익의 핵심**이 되어야 합니다.

**즉시 조치 사항:** 블로그 글 본문 중간(스크롤 40%~60% 구간)과 글 하단에 인아티클(In-Article) 광고를 배치하고, 도구 페이지에는 계산 결과 하단에 네이티브 광고 형식을 적용해야 합니다. 또한 **자동 광고(Auto Ads)**보다는 수동 배치가 고수익 키워드에서 더 유리합니다.

### **[개선 🟡] 7. 블로그 콘텐츠 E-E-A-T(경험·전문성·권위·신뢰) 강화 필요**

구글은 금융/세금 분야를 **YMYL(Your Money or Your Life)** 카테고리로 분류하여 E-E-A-T 기준을 매우 엄격하게 적용합니다. 현재 사이트는 "계산 결과는 참고용"이라는 면책 고지가 있지만, **저자 프로필(Author Bio)**, **세무사/전문가 검토 표시**, **최종 업데이트 날짜** 등이 블로그 글에 명시되어 있지 않습니다. 이는 구글이 콘텐츠의 신뢰도를 낮게 평가하는 주요 원인이 됩니다.

**즉시 조치 사항:** 각 블로그 글 상단에 "이 글은 ○○○(세금 전문 콘텐츠 팀)이 작성했습니다", "최종 업데이트: 2026년 5월"과 같은 정보를 추가하고, About 페이지에 사이트 운영자 전문성을 명확히 기재해야 합니다. 가능하다면 실제 세무사의 감수 의견을 추가하면 신뢰도가 크게 향상됩니다.

### **[개선 🟡] 8. 롱테일 키워드 콘텐츠 보강 필요**

현재 블로그에는 "코인 세금 2027", "업비트 CSV 다운로드" 등 핵심 키워드 위주로 구성되어 있습니다. 그러나 경쟁이 낮고 전환율이 높은 **롱테일 키워드** 콘텐츠가 더 필요합니다. 예를 들어, "업비트에서 비트코인 팔았을 때 세금 얼마나 내야 하나요", "코인 수익 1000만원 세금 계산", "해외 거래소 바이낸스 세금 신고 방법 한국" 같은 질문형 롱테일 키워드는 경쟁이 낮으면서 검색 의도가 명확한 고가치 트래픽을 가져옵니다.

**즉시 조치 사항:** 네이버 키워드 도구(searchad.naver.com)와 구글 키워드 플래너에서 "코인 세금" 관련 롱테일 키워드 50개를 발굴하고, 월 4~8개의 新 블로그 글을 추가해야 합니다. 특히 "수익 구간별 세금 시뮬레이션(200만원, 500만원, 1000만원, 5000만원)" 같은 구체적 계산 사례 글은 검색 클릭률이 매우 높습니다.

### **[개선 🟡] 9. 소셜 시그널 & 백링크 구축 전략 부재**

구글 SEO에서 외부 백링크(Backlink)는 여전히 핵심 순위 요소입니다. 현재 사이트는 독립 도메인(`cryptotax.cloud`)이므로 도메인 권위도(DA)를 높이기 위한 외부 링크 확보가 필수입니다. 사이트에 유저 후기가 유튜브/X/네이버 카페 형태로 나열되어 있으나, 이는 실제 외부 사이트에서 링크가 들어오는 것이 아닌 단순 콘텐츠 인용입니다.

**즉시 조치 사항:** 네이버 블로그/티스토리 운영자들과의 협업 글 작성(게스트 포스팅), 코인 관련 네이버 카페/커뮤니티에 사이트 링크 자연스럽게 노출, 유튜브 코인 채널 설명란에 사이트 링크 확보, 그리고 가장 중요하게는 **실제 세무사/회계사 블로그에서 외부 언급/링크**를 유도하는 PR 활동이 필요합니다.

### **[개선 🟡] 10. 사이트맵에 중복 URL 구조 발견**

sitemap.xml을 분석한 결과, `/blog/coin-tax-2027-guide.html`과 `/blog/coin-tax/2027-guide.html` 처럼 **유사한 주제의 URL이 서로 다른 경로에 중복으로 존재**하는 패턴이 발견됩니다. 또한 `/market/bitcoin-rainbow-chart.html`과 `/tools/bitcoin-rainbow-chart.html`처럼 동일 콘텐츠가 두 경로에 있는 경우도 보입니다. 이는 **중복 콘텐츠(Duplicate Content)** 문제로 구글의 크롤 예산을 낭비하고 페이지 권위도를 분산시킵니다.

**즉시 조치 사항:** 각 중복 페이지에 명확한 `canonical` 태그를 추가하거나 301 리다이렉트로 하나의 URL로 통합하고, sitemap에서 정규(canonical) URL만 남겨야 합니다.

## **💰 애드센스 수익 극대화 핵심 전략**

금융/세금 키워드는 한국 애드센스 기준 **CPC 500원~3,000원** 수준으로 최상위 카테고리입니다. 트래픽이 일 1,000명일 때 CTR 2%, CPC 800원으로 계산하면 월 약 **48만원**, 일 5,000명이면 **월 240만원** 수준입니다. 핵심은 **계산기 도구 페이지보다 정보성 블로그 글 트래픽**이 광고 수익에 유리하므로, 블로그 콘텐츠 확장을 최우선 전략으로 삼아야 합니다. 특히 2026년 하반기부터 2027년 1월 시행을 앞두고 "코인 세금" 관련 검색량이 폭발적으로 증가할 것으로 예상되므로, **지금부터 콘텐츠를 선점하는 것이 매우 중요한 시점**입니다.
