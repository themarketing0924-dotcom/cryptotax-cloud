현재 88점에서 **98점(최상위 SEO 등급)**으로 도약하기 위해 가장 시급한 것은 **사용자 클릭률(CTR) 최적화**와 **서버 응답성 강화**, 그리고 **네이버봇 수집 효율 극대화**입니다.

이를 위해 Replit 환경에서 즉시 실행하거나 설정에 반영할 수 있는 지침을 정리해 드립니다.

### **1. 98점을 위해 반드시 해야 할 3가지 (Action Plan)**

1.  **연도 및 문구 최신화 (CTR 개선):** 현재 '2027년'으로 되어 있는 메타 태그를 사용자가 가장 많이 검색하는 '2025~2026년' 및 '최신' 키워드로 교체해야 합니다.
2.  **서버 응답 안정화:** 네이버봇이 사이트를 수집할 때 지연이 발생하지 않도록 정적 자산(CSS/JS)을 압축하고 캐싱 설정을 점검해야 합니다.
3.  **설명(Description) 누락 해결:** SEO 진단에서 발견된 누락 페이지 1건을 즉시 채워야 합니다.

### **2. Replit 환경 최적화 및 코드 수정 지침**

Replit에서 웹 프로젝트를 운영 중이시라면, 다음의 명령과 코드 수정을 차례대로 진행하십시오.

#### **Step 1: HTML 메타 태그 일괄 최적화 (Copy & Paste)**
모든 HTML 파일(`index.html`, `tools/index.html` 등)의 `<head>` 섹션 내 문구를 다음과 같이 변경하십시오. (사용자 클릭 유도 문구 반영)

```html
<!-- 메인 페이지 및 도구 페이지 권장 메타 구조 -->
<title>코인 세금 계산기 2025-2026 | 업비트·빗썸 1초 계산</title>
<meta name="description" content="2025년 가상자산 과세 완벽 대응! 업비트, 빗썸 수수료부터 양도소득세 22% 즉시 계산. 회원가입 없이 무료로 19종 코인 도구를 사용하세요.">

<!-- Open Graph (카톡/SNS 공유용) -->
<meta property="og:title" content="코인 세금, 안 내면 큰일납니다! 1초 계산기">
<meta property="og:description" content="업비트·빗썸 투자자 필수! 내 코인 세금과 수수료를 즉시 계산해보세요.">
```

#### **Step 2: 수집 효율을 위한 Robots.txt 업데이트**
수집 제한 페이지 문제를 해결하기 위해 Replit 루트 디렉토리의 `robots.txt`를 다음과 같이 수정하십시오.

```text
User-agent: *
Allow: /
Allow: /blog/
Allow: /tools/
Sitemap: https://cryptotax.cloud/sitemap.xml
```

#### **Step 3: 서버 응답 속도 개선 (Shell 명령)**
Replit 콘솔(Shell)에서 다음 명령어를 실행하여 불필요한 파일을 정리하고 의존성을 최적화하여 서버 부하를 줄이십시오. (Node.js 환경 기준)

```bash
# 1. 사용하지 않는 패키지 정리 및 최적화 설치
npm prune && npm install

# 2. 정적 파일 압축 (압축 라이브러리가 있을 경우)
# 만약 이미지가 많다면 아래 명령어로 크기를 줄이는 공정을 제안합니다.
# (Replit 환경에 따라 다를 수 있으나 일반적인 성능 개선용)
find . -name "*.js" -type f -exec npx terser {} -o {} \;
```

### **3. 네이버 서치어드바이저 즉시 실행 지침 (콘솔 작업 후)**

코드를 수정하고 Replit 배포가 완료되었다면, 네이버 서치어드바이저에서 다음 과정을 **즉시** 수행해야 점수가 갱신됩니다.

1.  **[요청] > [페이지 수집]:** 
    *   `https://cryptotax.cloud/` (메인)
    *   `https://cryptotax.cloud/tools/` (도구 모음)
    *   위 두 주소를 입력하고 **수집 요청**을 눌러 네이버봇을 강제로 호출하십시오.
2.  **[요청] > [사이트맵 제출]:**
    *   만약 최근에 새로운 도구나 블로그 글을 추가했다면, `sitemap.xml` 경로를 다시 한번 입력하여 제출하십시오.
3.  **[검증] > [URL 검사]:**
    *   수정된 `2025-2026` 문구가 정상적으로 수집되는지 확인하십시오.
