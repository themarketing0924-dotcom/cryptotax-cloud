## **🟡 MEDIUM (2~4주 내)**

**[M-1] AEO(Answer Engine Optimization) — 직접 답변 구조 최적화**

2026년 AEO의 핵심은 "질문-답변 쌍을 명확하게 마크업하여 AI가 그대로 인용할 수 있게 만드는 것"입니다. 현재 블로그 글들은 좋은 내용을 담고 있지만, AI가 바로 추출할 수 있는 **명확한 Q&A 블록 구조**가 부족합니다. 각 블로그 글 상단에 아래 형식의 직접 답변 섹션을 추가하세요.

```html
<!-- AEO 최적화: 직접 답변 블록 -->
<div itemscope itemtype="https://schema.org/Question">
  <h2 itemprop="name">코인 세금 22%는 어떻게 계산하나요?</h2>
  <div itemscope itemtype="https://schema.org/Answer" itemprop="acceptedAnswer">
    <div itemprop="text">
      <p><strong>계산식:</strong> (연간 수익 - 250만원 기본공제) × 22%</p>
      <p>예시: 수익 1,000만원 → (1,000만 - 250만) × 22% = <strong>165만원</strong></p>
      <p>소득세 20% + 지방소득세 2% = 합산 22%이며, 2027년 1월 1일부터 적용됩니다.</p>
    </div>
  </div>
</div>
```

**[M-2] GEO(Generative Engine Optimization) — AI 인용 최적화 5원칙**

2025~2026년 연구에 따르면 Perplexity와 ChatGPT에 인용되는 콘텐츠의 공통점은 다음과 같습니다.

첫째, **인용 가능한 통계와 수치**가 본문에 포함되어 있어야 합니다. 현재 블로그 글들은 이 부분이 훌륭합니다(22%, 250만원, 2027년 등). 이를 더 강화하세요. 둘째, **법령 직접 인용**이 필요합니다. `소득세법 제87조의2`를 각 글의 첫 문단에서 명시적으로 언급하는 것이 중요합니다. AI는 법령 근거가 있는 콘텐츠를 더 신뢰합니다. 셋째, **저자 권위 신호** 추가입니다. About 페이지에 운영자 또는 감수자의 전문 배경을 명시하고, 블로그 글마다 `by CryptoTax.cloud 편집팀 | 소득세법 기준 검토`와 같은 byline을 추가하세요. 넷째, **외부 권위 기관 링크**입니다. 국세청(`nts.go.kr`), 국가법령정보센터(`law.go.kr`) 링크가 일부 글에 있는 것은 좋습니다. **모든 세금 관련 글에 일관되게** 적용하세요. 다섯째, **정기 업데이트 표시**입니다. 각 글에 `최종 업데이트: 2026년 5월`을 명시하면 AI가 최신 정보로 인식합니다.

**[M-3] Core Web Vitals — 측정 후 통과 기준 확인 필수**

구글 2026년 기준 통과 기준은 다음과 같습니다.

$$\text{LCP (Largest Contentful Paint)} \leq 2.5\text{초}$$

$$\text{INP (Interaction to Next Paint)} \leq 200\text{ms}$$

$$\text{CLS (Cumulative Layout Shift)} \leq 0.1$$

메인 페이지의 CSS가 인라인 스타일로 `<head>`에 직접 삽입되어 있어 렌더링 블로킹 가능성이 있습니다. 또한 이미지들이 외부 CDN(`sspark.genspark.ai`)에서 로딩되는 구조인데, 이 CDN의 응답 속도가 LCP에 직결됩니다. 즉시 `https://pagespeed.web.dev`에서 측정 후 문제 항목을 파악하세요.
