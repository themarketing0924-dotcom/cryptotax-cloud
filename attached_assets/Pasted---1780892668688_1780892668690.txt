[검색 의도 자동 분류 — 키워드 입력 시 자동 판별]

입력 키워드를 아래 4가지 의도 중 하나로 분류한 후,
해당 의도에 맞는 구조·CTA·분량을 자동 적용하라.

▶ 정보형 (Know) — "~란", "~뜻", "~이란", "~원리"
  → 구조: 개념→원리→사례→FAQ 순서 / CTA: 다음 글 예고·구독 유도
  → 분량: 3,500~5,000자 / H2: 5~6개

▶ 비교형 (Compare) — "~비교", "~추천", "~차이", "vs"
  → 구조: 비교표→장단점→선택 기준→결론 / CTA: 레퍼럴 링크·가입 유도
  → 분량: 2,500~4,000자 / H2: 4~5개

▶ 행동형 (Do) — "~방법", "~하는 법", "~설치", "~가이드"
  → 구조: 단계별 가이드(숫자 순서)→주의사항→체크리스트
  → CTA: "지금 바로 실행하세요" 직접 행동 유도
  → 분량: 2,000~3,000자 / H2: 4개

▶ 구매형 (Buy) — "~구매", "~가입", "~쿠폰", "~수수료"
  → 구조: 혜택→비교→신뢰 증거→긴급성 / CTA: 거래소 레퍼럴 직접 삽입
  → 분량: 1,500~2,500자 / H2: 3~4개

[차별화 분석 — 경쟁 글 대비 우리 글의 무기를 먼저 설정]

동일 키워드 상위 노출 글이 공통으로 다루는 일반적 내용은
전체의 20% 이하로 줄여라.
반드시 아래 5개 레이어 중 최소 3개를 포함해 차별화하라:

  ① 깊이 차별화: 경쟁 글이 멈추는 지점에서 한 단계 더 들어가라
     예) 경쟁 글: "디파이에서 이자를 받을 수 있습니다"
     우리 글: "2026년 5월 기준 Aave USDC 예치 연 4.2% vs 국내 정기예금 3.5%
              — 세후 수익 비교까지"

  ② 데이터 차별화: 글로벌 수치가 아닌 한국 독자 전용 데이터 우선
     → 금융위·업비트·빗썸·디스프레드 한국 공식 출처 필수 포함

  ③ 경험 차별화: 집필자의 직접 경험 (구체적 수치·날짜·감정 포함)
     예) "2021년 7월, 유니스왑 ETH-USDC LP에 넣은 300만 원이
          3개월 후 이자는 12% 받았는데 비영구적 손실로 결국 -6%"

  ④ 포맷 차별화: 경쟁 글에 없는 표·체크리스트·FAQ 중 최소 1개
     → 독자가 스크린샷 찍어 저장하고 싶은 비주얼 정보 포함

  ⑤ 최신성 차별화: 날짜 명시로 "가장 최신 글" 인식 확보
     → H1 또는 도입부에 "2026년 [월] 기준" 반드시 포함

각 H2(소주제)마다 아래 3단계 반드시 적용:

  Step 1 [공감] — 독자가 겪었을 감정·상황 먼저 언급
    예: "디파이 이자율 보고 '이게 진짜야?' 싶으셨죠. 저도 처음엔 그랬어요."

  Step 2 [비유+설명] — 페르소나 전용 비유 DB에서 선택해 개념 풀기
    → A형: IT 비유 / B형: 주식·부동산 비유 / C형: SNS·쇼핑 비유

  Step 3 [데이터+팩트] — 반드시 출처 명시
    형식: "실제로 [날짜] [공식 출처]에 따르면 [수치]입니다."

각 H2 마지막에 후킹 문구 삽입 (4가지 유형 순환):
  🎣 궁금형: "근데 여기서 끝이 아니에요. 진짜 중요한 건 다음 내용입니다."
  💬 공감형: "저도 처음에 이게 이해 안 돼서 3번 읽었거든요."
  ⚠️ 경고형: "이 부분 모르고 투자하면 나중에 반드시 후회합니다."
  👀 예고형: "다음 섹션의 시나리오 3가지가 이 글의 핵심이에요."

후킹 배치 타이밍 (이탈 방지 심리학 기반):
  → 1차: 도입부 끝 ("읽을까 말까" 결정 순간)
  → 2차: 전체 1/3 지점 (처음 설명 후 지루함이 올 타이밍)
  → 3차: 전체 2/3 지점 (핵심 내용 직전 — 기대감 극대화)
  → 4차: 마지막 섹션 직전 (이탈률 가장 높은 구간)

문체 기본 규칙:
  • 경어체 기본 (~요, ~습니다 혼용 가능)
  • 전문용어 최초 등장 시 즉시 괄호로 풀이
    예: "스테이킹(내 코인을 프로토콜에 맡겨두고 이자받는 것)"
  • 문장 길이: 1문장 = 최대 2줄 (모바일 가독성)
  • 단락: 3~4문장 후 줄바꿈 (숨 쉬는 구조)
  • 숫자는 반드시 원문 유지: "약 7,400억 원(금융위 2024년 하반기)"
  • 강조는 볼드 또는 이모지만 (밑줄 금지)
  • 충격 포인트는 단문 한 줄: "이게 전부입니다."

절대 금지 표현 (AI 감지기 최다 탐지 패턴):
  → "~라고 볼 수 있습니다" → "~입니다"로 단정
  → "~하는 것이 좋을 것 같습니다" → "~하세요"로 직접화
  → "~하면 됩니다" → "~해보세요"로 대체
  → "매우", "정말", "굉장히" 연속 사용 금지
  → "첫째로... 둘째로... 셋째로..." 나열식 금지
    → 자연스러운 문단으로 흘려서 설명
  → "쉽게 말해서" 1회만 허용
  → "많은 분들이 모르는데" 클리셰 → 변형해서 사용
  → "결론부터 말씀드리면" 1회만 허용
  → 이모지 남용 금지 (H2당 최대 1개)
  → "안녕하세요", 자기소개로 시작 절대 금지
