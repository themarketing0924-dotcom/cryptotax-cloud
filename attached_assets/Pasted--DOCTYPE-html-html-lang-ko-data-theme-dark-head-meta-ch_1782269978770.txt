    <h2 class="card-title" style="font-size:1.05rem;">알트코인 시즌이란? 코린이를 위한 완전 설명</h2>

    <h3 style="font-size:.95rem;font-weight:800;margin:0 0 8px;color:var(--purple);">🌊 알트시즌이 오는 이유</h3>
    <p style="font-size:.85rem;color:var(--text-sub);margin-bottom:14px;line-height:1.75;">비트코인 강세장이 충분히 진행되면 "비트코인만으로는 더 큰 수익을 얻기 어렵다"는 심리가 형성됩니다. 이때 자금이 이더리움, 솔라나, 리플 등 알트코인으로 이동하며 알트시즌이 시작됩니다. BTC 도미넌스 하락이 선행 신호로 자주 관찰됩니다.</p>

    <h3 style="font-size:.95rem;font-weight:800;margin:0 0 8px;color:var(--purple);">📅 역사적 알트시즌 패턴</h3>
    <p style="font-size:.85rem;color:var(--text-sub);margin-bottom:14px;line-height:1.75;">역사적으로 비트코인 반감기(약 4년 주기) 이후 6~18개월 시점에 알트시즌이 찾아왔습니다. 2021년 알트시즌에는 이더리움이 +1,000%, 솔라나가 +10,000% 이상 상승했습니다. 그러나 알트시즌은 비트시즌보다 변동성이 훨씬 크고 짧게 끝나는 경향이 있어 주의가 필요합니다.</p>

    <h3 style="font-size:.95rem;font-weight:800;margin:0 0 8px;color:var(--red);">⚠️ 알트시즌의 함정</h3>
    <p style="font-size:.85rem;color:var(--text-sub);line-height:1.75;">알트코인 상승은 빠르고 하락도 극단적입니다. 알트시즌 고점에서 매수하면 -80~-95%까지 하락하는 경우도 있습니다. 지수 75 이상이면 점차 수익 실현과 절세 전략을 병행하는 것이 중요합니다.</p>

    <div class="card-title">❓ 자주 묻는 질문 (FAQ)</div>

    <details>
      <summary>알트코인 시즌 지수 75 이상이면 무조건 팔아야 하나요?</summary>
      <p>지수 75 이상은 과열 신호지만 반드시 매도해야 한다는 뜻은 아닙니다. 역사적으로 알트시즌 지수가 75를 넘어도 수개월간 지속된 경우가 많습니다. 단, 이 구간에서는 수익 실현 계획을 미리 세우고, 매도 시 발생하는 양도세(22%)를 계산해두는 것이 중요합니다. <a href="/tools/tax-calculator.html" style="color:var(--orange)">세금 계산기 바로가기 →</a></p>
    </details>
    <details>
      <summary>BTC 도미넌스와 알트시즌 지수의 차이는?</summary>
      <p>BTC 도미넌스는 전체 코인 시가총액 중 BTC가 차지하는 비율입니다. 알트시즌 지수는 상위 50개 코인 중 90일 수익률이 BTC보다 높은 코인의 비율입니다. 도미넌스는 시총 기반, 지수는 수익률 기반이라 서로 다른 관점에서 시장을 봅니다. 보통 도미넌스 하락 = 알트시즌 지수 상승 방향으로 연동되는 경향이 있습니다.</p>
    </details>
    <details>
      <summary>알트시즌에 어떤 알트코인에 투자해야 하나요?</summary>
      <p>이 지수는 투자 추천 서비스가 아닙니다. 일반적으로 알트시즌에는 시가총액이 크고 거래량이 활발한 이더리움(ETH), 솔라나(SOL), 리플(XRP) 등이 먼저 상승하는 경향이 있습니다. 소형 알트코인은 상승폭이 크지만 리스크도 극단적으로 높습니다. 위 성과표 상위 코인을 참고하되 반드시 본인이 리서치한 코인에만 투자하세요.</p>
    </details>
    <details>
      <summary>지수가 0에 가까울 때 알트코인을 사면 저점 매수인가요?</summary>
      <p>지수 0~25(비트시즌)는 알트코인이 BTC 대비 부진한 구간입니다. 장기적 관점에서는 저점 매수 기회가 될 수 있지만, 비트시즌은 더 길게 지속될 수 있습니다. 한 번에 전액 투입보다는 <a href="/tools/dca-calculator.html" style="color:var(--orange)">DCA(분할 매수)</a> 전략으로 리스크를 분산하는 것을 권장합니다.</p>
    </details>
    <details>
      <summary>스테이블코인은 왜 계산에서 제외하나요?</summary>
      <p>USDT, USDC 등 스테이블코인은 달러 가치에 연동되어 가격이 거의 변하지 않습니다. 따라서 BTC 대비 수익률이 사실상 의미가 없어 알트시즌 지수 계산에서 제외합니다. 지수는 순수하게 가격 변동이 있는 암호화폐만 측정합니다.</p>
    </details>
    <details>
      <summary>알트코인 수익에도 세금이 붙나요?</summary>
      <p>네, 2027년부터 알트코인을 포함한 모든 가상자산 양도소득세 22%(소득세 20% + 지방소득세 2%)가 부과됩니다. 연간 250만원까지는 기본공제가 적용됩니다. 알트시즌에 큰 수익이 발생할 수 있는 만큼 <a href="/tools/tax-calculator.html" style="color:var(--orange)">미리 세금을 계산</a>해두는 것이 중요합니다.</p>
    </details>

function drawGauge(score) {
  const canvas = document.getElementById('gaugeCanvas');
  if (!canvas) return;
  const ctx = canvas.getContext('2d');
  const W = canvas.width, H = canvas.height;
  const cx = W / 2, cy = H * 0.78;
  const R = W * 0.42;
  ctx.clearRect(0, 0, W, H);

  // 배경 호 세그먼트 (4구간)
  const segments = [
    { from: Math.PI, to: Math.PI*1.25, color: '#58a6ff' },
    { from: Math.PI*1.25, to: Math.PI*1.5,  color: '#3fb950' },
    { from: Math.PI*1.5,  to: Math.PI*1.75, color: '#f0b429' },
    { from: Math.PI*1.75, to: Math.PI*2,    color: '#f85149' },
  ];
  segments.forEach(s => {
    ctx.beginPath();
    ctx.arc(cx, cy, R, s.from, s.to);
    ctx.lineWidth = 28;
    ctx.strokeStyle = s.color + '33';
    ctx.stroke();
  });

  // 현재 점수 호
  const scoreAngle = Math.PI + (score / 100) * Math.PI;
  const scoreColor = score < 25 ? '#58a6ff' : score < 50 ? '#3fb950' : score < 75 ? '#f0b429' : '#f85149';
  const grad = ctx.createLinearGradient(cx - R, cy, cx + R, cy);
  grad.addColorStop(0, '#58a6ff');
  grad.addColorStop(0.33, '#3fb950');
  grad.addColorStop(0.66, '#f0b429');
  grad.addColorStop(1, '#f85149');
  ctx.beginPath();
  ctx.arc(cx, cy, R, Math.PI, scoreAngle);
  ctx.lineWidth = 28;
  ctx.strokeStyle = grad;
  ctx.lineCap = 'round';
  ctx.stroke();

  // 니들
  const needleAngle = Math.PI + (score / 100) * Math.PI;
  const nx = cx + (R - 14) * Math.cos(needleAngle);
  const ny = cy + (R - 14) * Math.sin(needleAngle);
  ctx.beginPath();
  ctx.moveTo(cx, cy);
  ctx.lineTo(nx, ny);
  ctx.lineWidth = 3;
  ctx.strokeStyle = scoreColor;
  ctx.lineCap = 'round';
  ctx.stroke();
  ctx.beginPath();
  ctx.arc(cx, cy, 7, 0, Math.PI * 2);
  ctx.fillStyle = scoreColor;
  ctx.fill();
}

function renderHistoryChart(data) {

    ctx.fillText(v, padL - 6, y + 4);

  const step = Math.ceil(data.length / 6);
  data.forEach((d, i) => {
    if (i % step !== 0 && i !== data.length - 1) return;

/* ─────────────────────────────────────────────
   6. CoinGecko API 호출 — 레이트리밋 안전 fetch
   (무료 데모키: 30req/min → 각 요청 2초 간격)
───────────────────────────────────────────── */
const GCK = 'https://api.coingecko.com/api/v3';
const HEADERS = { 'Accept': 'application/json' };

async function cgFetch(url, retries = 2) {
  for (let attempt = 0; attempt <= retries; attempt++) {
    try {
      const res = await fetch(url, { headers: HEADERS });
      if (res.status === 429) { await sleep(6000); continue; }
      if (!res.ok) throw new Error(`HTTP ${res.status}`);
      return await res.json();
    } catch(e) {
      if (attempt === retries) throw e;
      await sleep(2000);
    }
  }
}

async function loadAll() {
  // ── 7-1. Top 50 코인 리스트 + 현재가 ──
  setProgress(5);
  let top50;
  try {
    top50 = await cgFetch(
      `${GCK}/coins/markets?vs_currency=usd&order=market_cap_desc&per_page=80&page=1&sparkline=false&price_change_percentage=24h,7d`
    );
  } catch(e) {
    console.error('Top50 fetch fail:', e);
    showApiWarning('coingecko-markets');
    return;
  }
  // 스테이블·래핑 필터
  const filtered = top50.filter(c => !STABLE_IDS.has(c.id) && c.id !== 'bitcoin');
  const altList = filtered.slice(0, 50);  // 상위 50개 알트
  setProgress(15);

  // ── 7-2. BTC 90일 히스토리 ──
  let btcHistory;
  try {
    btcHistory = await cgFetch(`${GCK}/coins/bitcoin/market_chart?vs_currency=usd&days=91&interval=daily`);
  } catch(e) {
    console.error('BTC 90d fail:', e);
  }
  setProgress(25);

  // BTC 90일 수익률 계산
  let btcReturn90 = null;
  if (btcHistory && btcHistory.prices && btcHistory.prices.length >= 90) {
    const prices = btcHistory.prices;
    const p0 = prices[prices.length - 91]?.[1] || prices[0][1];
    const p1 = prices[prices.length - 1][1];
    btcReturn90 = ((p1 - p0) / p0) * 100;
  }

  // BTC 현재가
  const btcNow = btcHistory?.prices?.slice(-1)[0]?.[1] || 0;
  const btc7dEntry = top50.find(c => c.id === 'bitcoin');
  const btc7dReturn = btc7dEntry?.price_change_percentage_7d_in_currency || null;

  setProgress(35);

  // ── 7-3. 상위 20 알트코인 90일 히스토리 — 병렬 ──
  const altFor90 = altList.slice(0, 20);
  const DELAY_MS = 800; // 무료 티어 레이트리밋 회피

  const alt90Results = await Promise.allSettled(
    altFor90.map((coin, i) =>
      sleep(i * DELAY_MS).then(() =>
        cgFetch(`${GCK}/coins/${coin.id}/market_chart?vs_currency=usd&days=91&interval=daily`)
          .then(data => ({ id: coin.id, data }))
          .catch(() => ({ id: coin.id, data: null }))
      )
    )
  );

  setProgress(70);

  // ── 7-4. 90일 수익률 계산 ──
  const coinReturns = {};
  alt90Results.forEach(res => {
    if (res.status !== 'fulfilled') return;
    const { id, data } = res.value;
    if (!data?.prices || data.prices.length < 10) return;
    const prices = data.prices;
    const p0 = prices[0][1];
    const p1 = prices[prices.length - 1][1];
    if (p0 > 0) coinReturns[id] = ((p1 - p0) / p0) * 100;
  });

  // altList 전체에 24h 기반 fallback 수익률도 저장
  const tableData = altList.map((coin, idx) => {
    const r90 = coinReturns[coin.id] ?? null;
    const vsBtc = (r90 != null && btcReturn90 != null) ? r90 - btcReturn90 : null;
    return {
      rank: idx + 1,
      id: coin.id,
      name: coin.name,
      symbol: coin.symbol.toUpperCase(),
      image: coin.image,
      price: coin.current_price || 0,
      return90: r90,
      vsBtc,
      change24h: coin.price_change_percentage_24h || 0,
      change7d: coin.price_change_percentage_7d_in_currency || null,
    };
  });

  // ── 7-5. 진짜 알트시즌 지수 계산 ──
  const measured = tableData.filter(c => c.return90 != null);
  const beating  = measured.filter(c => c.return90 > (btcReturn90 || 0));
  const altScore90 = measured.length > 0 ? Math.round((beating.length / measured.length) * 100) : null;

  // 24H 단기 지수 (기존 로직 유지)
  const pos24h = altList.filter(c => (c.change24h || 0) > (btc7dEntry?.price_change_percentage_24h || 0)).length;
  const score24h = Math.round((pos24h / altList.length) * 100);

  setProgress(85);

  // ── 7-6. 공포탐욕 지수 ──
  let fgData = null;
  try {
    const fg = await cgFetch('https://api.alternative.me/fng/?limit=1');
    fgData = fg?.data?.[0];
  } catch(e) {}

  setProgress(90);

  // ── 7-7. 글로벌 데이터 (BTC 도미넌스, 총 시총) ──
  let globalData = null;
  try {
    globalData = await cgFetch(`${GCK}/global`);
  } catch(e) {}

  setProgress(95);

  // ── 7-8. 히스토리 지수 계산 (최근 30일) ──
  const historyScores = await buildHistoryScores(btcHistory, altFor90, alt90Results);

  setProgress(100);

  // ── 7-9. UI 업데이트 ──
  updateUI({
    altScore90, score24h, btcReturn90, tableData,
    fgData, globalData, historyScores, btc7dReturn,
    btcNow, beating: beating.length, measured: measured.length
  });
}

/* ─────────────────────────────────────────────
   8. 히스토리 지수 (30일치) 계산
   BTC histoday daily + 상위 10코인 daily로 매일 점수 재계산
───────────────────────────────────────────── */
async function buildHistoryScores(btcHistory, altFor90, alt90Results) {
  if (!btcHistory?.prices || btcHistory.prices.length < 31) return [];

  const btcPrices = btcHistory.prices; // [[ts, price], ...]
  const n = btcPrices.length; // ~92개 데이터포인트
  const results = [];

  // 상위 10코인 histoday 데이터 추출
  const altPriceArrays = [];
  for (const res of alt90Results.slice(0, 10)) {
    if (res.status !== 'fulfilled') continue;
    const { data } = res.value;
    if (!data?.prices || data.prices.length < 31) continue;
    altPriceArrays.push(data.prices);
  }

  // 최근 30일 루프 (마지막 30 인덱스)
  const startIdx = Math.max(n - 30, 0);
  for (let dayIdx = startIdx; dayIdx < n; dayIdx++) {
    const ts = btcPrices[dayIdx][0];
    const date = new Date(ts).toISOString().slice(0, 10);

    // 이 날 기준으로 90일 전 인덱스
    const prev90Idx = dayIdx - 90;
    if (prev90Idx < 0) { results.push({ date, score: 50 }); continue; }

    const btcP0 = btcPrices[prev90Idx][1];
    const btcP1 = btcPrices[dayIdx][1];
    const btcR = btcP0 > 0 ? (btcP1 - btcP0) / btcP0 * 100 : 0;

    let beat = 0, total = 0;
    for (const altPrices of altPriceArrays) {
      if (dayIdx >= altPrices.length) continue;
      const aPrev = prev90Idx < altPrices.length ? altPrices[prev90Idx][1] : altPrices[0][1];
      const aNow  = altPrices[dayIdx][1];
      if (aPrev > 0) {
        const aR = (aNow - aPrev) / aPrev * 100;
        total++;
        if (aR > btcR) beat++;
      }
    }
    const score = total > 0 ? Math.round((beat / total) * 100) : 50;
    results.push({ date, score });
  }
  return results;
}

/* ─────────────────────────────────────────────
   9. UI 업데이트
───────────────────────────────────────────── */
function updateUI({ altScore90, score24h, btcReturn90, tableData,
                    fgData, globalData, historyScores, btc7dReturn,
                    btcNow, beating, measured }) {

  const score = altScore90 ?? score24h;
  const phaseInfo = score >= 75 ? { label:'🔴 알트코인 시즌!', color:'#f85149', bg:'rgba(248,81,73,.12)' }
                  : score >= 50 ? { label:'🟡 중립 (알트 우세)', color:'#f0b429', bg:'rgba(240,180,41,.1)' }
                  : score >= 25 ? { label:'🟢 중립 (BTC 우세)', color:'#3fb950', bg:'rgba(63,185,80,.1)' }
                  : { label:'🔵 비트코인 시즌', color:'#58a6ff', bg:'rgba(88,166,255,.1)' };

  // 게이지
  drawGauge(score);
  const numEl = document.getElementById('gaugeScore');
  numEl.textContent = score;
  numEl.style.color = phaseInfo.color;
  const phaseEl = document.getElementById('gaugePhase');
  phaseEl.textContent = phaseInfo.label;
  phaseEl.style.background = phaseInfo.bg;
  phaseEl.style.color = phaseInfo.color;
  document.getElementById('gaugeUpdate').textContent = `마지막 업데이트: ${now()}`;

  // 스탯 카드
  const s90 = altScore90 != null
    ? `${altScore90}점 (${beating}/${measured})`
    : `—`;
  document.getElementById('statAlt90').textContent = s90;
  document.getElementById('statAlt90').style.color = phaseInfo.color;

  document.getElementById('stat24h').textContent = `${score24h}점`;
  document.getElementById('stat24h').style.color = score24h >= 75 ? '#f85149' : score24h >= 50 ? '#f0b429' : score24h >= 25 ? '#3fb950' : '#58a6ff';

  const btcReturnEl = document.getElementById('statBtc90');
  if (btcReturn90 != null) {
    btcReturnEl.textContent = pct(btcReturn90);
    btcReturnEl.style.color = btcReturn90 >= 0 ? 'var(--green)' : 'var(--red)';
  }

  // BTC 도미넌스
  const dom = globalData?.data?.market_cap_percentage?.btc;
  if (dom) document.getElementById('statDom').textContent = dom.toFixed(1) + '%';

  // 공포탐욕
  if (fgData) {
    document.getElementById('fgValue').textContent = fgData.value;
    document.getElementById('fgLabel').textContent = fgData.value_classification;
    const fv = parseInt(fgData.value);
    document.getElementById('fgValue').style.color = fv >= 70 ? '#f85149' : fv >= 50 ? '#f0b429' : fv >= 30 ? '#3fb950' : '#58a6ff';
  }

  // BTC 7일 추세
  if (btc7dReturn != null) {
    const el = document.getElementById('btc7d');
    el.textContent = pct(btc7dReturn);
    el.style.color = btc7dReturn >= 0 ? 'var(--green)' : 'var(--red)';
  }

  // ETH/BTC 비율
  const eth = tableData.find(c => c.id === 'ethereum');
  if (eth && btcNow) {
    document.getElementById('ethBtc').textContent = (eth.price / btcNow).toFixed(5);
  }

  // 총 시총
  const mc = globalData?.data?.total_market_cap?.usd;
  if (mc) document.getElementById('totalMcap').textContent = '$' + fmt(mc);

  // 히어로 업데이트
  document.getElementById('heroUpdated').textContent = now();
  document.getElementById('heroCoins').textContent = measured || tableData.length;

  // 국면 카드 활성화
  activatePhaseCard(score);

  // 히스토리 차트
  if (historyScores && historyScores.length > 0) {
    setTimeout(() => renderHistoryChart(historyScores), 100);
    document.getElementById('historyLoadingOverlay').classList.add('hidden');
  }

  // 성과표
  _tableData = tableData;
  renderTable();

  // 로딩 오버레이 제거
  document.getElementById('gaugeLoadingOverlay').classList.add('hidden');
  document.getElementById('tableLoadingOverlay').classList.add('hidden');
}
